Where a note goes in vrtti

This page is an example of a diagram of states. A diagram of states shows where a thing can be and which action moves it from one state to another. The content comes from vrtti, a note app (urza/editor). On each device, a note is in one of four states: Open, Recent, a space drawer, or Trash.

The diagram

The diagram leaves out edits from other devices, because an edit changes a note where it is and does not move it. A diagram of states shows only what moves the thing, and a table gives the details of each case.

The same states in a table

The table gives one row for each case. The tag of a state has the color of its box, so the reader connects a row with the diagram.
