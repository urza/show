Part 1 · Elements that explain

Text

A section starts with an h2, which has a line above it. A paragraph is not wider than 74 characters. Inside a sentence you can use bold for a term, code for the name of a file or a function, and a link.

A heading of the third level

It names one part of a section.

  • A list without numbers is for points of equal weight.
  • Write each point as a complete sentence.
  1. A list with numbers is for steps.
  2. It is also for points that the user refers to in a note.

A note is small and muted. It is for a remark of less importance, for example how you tested something.

Words on this page

A table without a head row is a list of words. Use it when the page has more than a few special words, because the user reads the page without the context of your session.

A special wordThe one meaning that the word has on this page.
A second wordOne sentence that a person outside the project understands.

Tables and tags

A table is good for a comparison, for example "today" and "after the change". It is inside a .scroll box, so a wide table scrolls on a phone and the page stays in place. A tag is a short mark in a cell or in an option.

The classes of the tags are new (green), less (red), same (grey), ask (amber) and rec (blue).

Diagrams

A diagram is an inline svg in a figure. Use it when the relation between things is the message: which part sends what to which part, and where something fails. The classes take their colors from the page, so the diagram is correct in the light and the dark theme.

Code

A code block is a pre with a code inside. The page colors a block that names its language in the class language-xx. data-title on the pre shows a file name above the code.

// Write & < > in code as &amp; &lt; &gt;
function total(items) {
  let sum = 0;
  for (let i = 0; i < items.length; i++) {
    sum = sum + items[i].price;
  }
  return sum;
}

Versions in tabs

.tabs shows one of its children at a time. Each child names its tab with data-tab, and the page makes the buttons. Use it to compare alternatives of the same code, for example the current code and the proposed code. The last button shows the versions side by side.

function total(items) {
  let sum = 0;
  for (let i = 0; i < items.length; i++) {
    sum = sum + items[i].price;
  }
  return sum;
}
function total(items) {
  return items.reduce((sum, item) => sum + item.price, 0);
}

The line above is <p class="tabs-all"></p>. Its buttons change all tabs of the page. Put it at the start of a page that has many comparisons.

Boxes

.tool is a box for a block that stands apart, for example a summary or a remark that does not belong to the text around it.

A folded block

details hides content that only some readers want. The user can ignore the details and decide from the text above them.

Mockups

A mockup is a drawing of the app, made with HTML and CSS. .shot is its backdrop, and .mock is one drawn screen. The styles of the drawn app are in the style of this file. They are a placeholder: on a real page, use the colors and the sizes of the real app.

Part 2 · Elements that ask

Questions

This section shows each type of question. On a real page, put each question directly below the content that explains it, and do not collect the questions at the end. The page gives each question its number.

Which answer do you select, when only one answer is possible?

Write here what the user needs for this decision. Each option is a row with the answer in bold and one sentence below it.

Where is the new button?

Use option cards when an answer changes what a person sees. Each card draws the same screen with one difference, so that the user sees only the decision. A tap on a drawing selects its card.

Which answers do you select, when more than one is possible?

You can select more than one answer.

A thing that is decided (you do not decide this)

Ask only about decisions that are open. When something is decided, say what you do and why. A heading that ends with "(you do not decide this)" makes that clear.

Which answer do you write, when the question has no options?

A question without options has one text field. The placeholder gives an example of an answer.
